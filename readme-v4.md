# Modunera Europe Platform V4

## Included
- Immersive German homepage and redesigned shared style system
- MC 1–MC 8 model selector
- Interactive visual configurator with pricing, saving, sharing and print-to-PDF
- Model comparison, delivery estimate, land-readiness, energy saving and hospitality ROI tools
- Rule-based Modunera planning assistant on all pages
- Lead capture workflow (localStorage + WhatsApp in static mode)
- Factory, projects, document center and customer production-status demo
- Legal placeholders and cookie preference layer
- German location SEO estate and Academy/FAQ preserved
- Core sitemap, hreflang foundation and structured data

## Credentials / source files required for full production integration
1. Real domain and hosting environment
2. CRM endpoint and API credentials (HubSpot, Pipedrive, Zoho or custom)
3. SMTP / transactional email provider
4. GA4, Google Tag Manager, Search Console, Meta Pixel and Clarity IDs
5. Company legal entity, address, registration, tax and DPO details
6. Verified certificates, warranty and technical documents
7. Real delivered-project photos/testimonials and permissions
8. CAD/GLB files for true free-rotation WebGL 3D models
9. Final price matrix, tax/customs logic and logistics tables
10. Authentication/backend for the customer production portal

## Static demo behavior
Forms and designs save locally in the browser and can open WhatsApp. No external data is transmitted until backend endpoints are connected.
