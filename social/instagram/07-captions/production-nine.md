# MODUNERA — production nine

## Posting order

**Publish from 9 down to 1**, same as the launch nine and for the same reason:
Instagram places the newest post top-left, so the tile meant for that corner
goes up last. One post per day keeps the checkerboard forming in front of
followers; posting all nine at once also works and lands the full grid.

This set follows the launch nine on the profile. Both are 3x3 checkerboards, so
the seam between them keeps the rule: a card never touches a card.

Each caption is one block: English, a rule, German, hashtags. Copy the whole
block. Every factual sentence below is either visible in the photograph or
already published on modunera.com; nothing is claimed beyond that.

## 4 · `post-4.jpg` · numeral · #97311A on #F5F5F5 — 6.95:1

```
2.55 metres wide — every model.

The one number that makes road delivery work. All eight models share the same base width; what changes per project is length, layout and route. Wider would mean special transport on every trip. This width means a house can simply travel.

—

2,55 Meter breit — jedes Modell.

Die eine Zahl, die Strassentransport möglich macht. Alle acht Modelle stehen auf derselben Basisbreite; was sich je Projekt ändert, sind Länge, Grundriss und Route. Breiter hiesse Sondertransport bei jeder Fahrt. Diese Breite heisst: Ein Haus kann einfach reisen.
```
