# Profile picture

Four options, all built from the two logo files already in `assets/brand/`.
No new logo is drawn and neither file is modified.

The mark is used rather than the full lockup: Instagram renders the avatar
at roughly 32 px beside a comment, where a wordmark is a grey smudge and a
symbol still reads. `compare.jpg` shows each option at 260, 56 and 32 px
against the white the feed is seen on, because the small sizes are where
the choice is actually made.

* **a-paper** — The site's own body ground. The safest match — a visitor moving from the website sees the same white.
* **b-cream** — The site's alternating section band. Warmer than paper and still a real token, closest to what the account uses now.
* **c-moss** — Forest green with the white mark. The most distinctive at 32 px, because it is the only option that is dark — it holds its shape against a white feed.
* **d-roof** — The roof red as ground. Loudest, and it gives up the red mark to do it.

The beige currently on the account is in neither the site nor the logo
file. It reads as deliberate on its own and as a different company once
the profile and the website are open together.
